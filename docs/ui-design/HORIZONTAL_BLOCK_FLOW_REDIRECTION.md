# Horizontal Block Flow Redirection

## 为什么继续从横向积木流转向槽位式

上一版已经从自由节点图转为横向积木流，但用户草图进一步指出：画面仍然太像“节点 + 端口 + 连线”。

新的方向是：

```text
slot-based horizontal block flow
槽位式横向积木流
```

核心变化：

- 线不是主要表达方式。
- 块与槽位才表达逻辑关系。
- 条件分支必须属于条件块结构。
- 分支内容直接贴到槽位后方。
