# Horizontal Block Flow Redirection

## 为什么转向横向积木流

上一版原型已经有卡片、端口、直接连线，但视觉上仍像传统自由节点图。用户反馈指出：

- 大屏下组件太小。
- 英文 UI 太多。
- 细线连接不直观。
- 画布不能拖动。
- 条件双输出不应该用漂浮文字和漂浮线表达。
- PixelLogic 应该更像横向拼积木，而不是自由节点电路图。

因此本轮把主方向改成 **横向积木流**。

## 新卡片结构

普通积木：

- 中文节点类型。
- 节点名称。
- 简短中文摘要。
- 左侧输入口。
- 右侧输出口。
- 状态：正常 / 警告 / 错误 / 已选中。

条件积木：

- 更高卡片。
- 左侧中部输入。
- 右侧上方“通过”。
- 右侧下方“失败”。

动作积木：

- 右侧保留“完成 / 错误”出口。
- 错误出口可弱化，但要可见。

## 连接视觉

连接从细曲线改为粗短的横向结构化连接。端口文字贴在卡片上，连接只负责表达从哪个出口到哪个输入。

支持：

- 悬停连接高亮上下游积木。
- 选中卡片高亮相关连接。
- 未连接端口使用虚线和红色提示。

## 画布交互

本轮原型真实实现：

- 拖拽平移。
- 滚轮缩放。
- 适应视图。
- 回到中心。
- 聚焦选中。

## 仍待用户确认

- 横向积木流是否作为主视觉方向。
- 条件双出口是否好懂。
- 卡片大小是否合适。
- 是否增加更明显的 Minecraft 质感。
- 是否继续进入真实编辑器交互设计。
