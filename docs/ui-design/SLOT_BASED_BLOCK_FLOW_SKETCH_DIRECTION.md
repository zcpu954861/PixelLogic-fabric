草图表达的是大块横向拼接，而不是传统节点图。上方是横向主链，下方是一个条件高块，右侧上下两个槽位分别连接分支。

## 设计判断

上一版横向积木流仍然杂乱，原因不是颜色，而是结构仍由线和端口主导。

本轮改为槽位式：

- 普通积木靠咬合边连接。
- 条件积木提供两个固定槽位。
- 分支块直接对齐槽位。
- 线缆只保留为短粗拼接条。

## 条件高块双槽位

条件块右侧常显：

- 通过：继续开始流程。
- 失败：写入调试记录。

这两个槽位必须属于卡片结构，不能漂浮在画布空白处。

## 横向流程保持

虽然参考 Scratch 的拼接直觉，但 PixelLogic 不采用竖向脚本堆叠。本轮仍然保持从左到右：

```text
命令触发 -> 条件判断 -> 通过分支动作
                    -> 失败分支调试
```
