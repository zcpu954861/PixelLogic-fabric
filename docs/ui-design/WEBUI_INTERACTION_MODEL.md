# PixelLogic WebUI 交互模型

## 工作台结构

- 顶部栏：PixelLogic、当前流程名、保存状态、测试运行、适应视图、回到中心、设置。
- 左侧栏：流程列表、积木库、快捷创建、模板入口。
- 中心：逻辑画布，承载槽位式横向积木流。
- 右侧栏：只编辑选中积木字段。
- 底部栏：验证问题、执行记录、调试日志。

## 槽位式横向积木流

逻辑仍从左到右推进，但流程关系主要由块与槽位表达：

- 普通块通过左右咬合边拼接。
- 条件块通过右侧上下槽位分支。
- 连接文本放在槽位或卡片结构上，不放在画布空白处。
- 选中条件块时，高亮相关拼接条和分支容器。

## 条件高块

条件判断是更高的独立块：

- 左侧接入上游触发器。
- 右侧上方：通过槽位。
- 右侧下方：失败槽位。

影响流程分支的逻辑必须在画布上可见，不能只藏在右侧属性面板。

## 动作错误处理

动作类积木默认只展示主路完成。错误输出折叠为小红色“错误处理”槽位，避免普通视图出现多余线缆。

## 画布交互

本轮静态原型已真实实现：

- 鼠标拖拽空白处平移。
- 滚轮缩放。
- 适应视图。
- 回到中心。
- 聚焦选中。
- 悬停拼接条时高亮上下游。
- 选中条件块时高亮相关槽位关系。
