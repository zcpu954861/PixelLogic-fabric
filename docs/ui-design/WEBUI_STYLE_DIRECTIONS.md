# PixelLogic WebUI 风格方向

## 已放弃作为主方向：线缆式节点图

上一版横向积木流仍然保留了明显的节点编辑器特征：

- 端口太像节点编辑器端口。
- 连线仍然承担主要理解成本。
- 多个圆形端口和标签让画面显得杂乱。
- 条件分支需要追踪连接。

## 当前推荐方向：槽位式横向积木流

槽位式横向积木流把“线”退到次要位置，用块和槽位表达逻辑：

- 大块横向拼接。
- 条件块更高。
- 通过 / 失败是条件块右侧的固定槽位。
- 分支块贴到槽位后方。
- 只保留短粗拼接条。

## 美术取向

当前实现继续保持克制 Pixel Craft：淡网格、粗边框、积木咬合、清楚状态色。

仍待用户确认：

- 是否更像用户草图。
- 是否需要更明显的 Minecraft 质感。
- 是否需要更像专业服务器后台。
- 咬合边是否要更强、更像拼图。
