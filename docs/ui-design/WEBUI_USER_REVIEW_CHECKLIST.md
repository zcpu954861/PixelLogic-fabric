# PixelLogic WebUI User Review Checklist

Use this checklist to review the static concept prototype.

- 是否喜欢整体风格？
- 是否需要更像 Minecraft / 更专业 / 更可爱 / 更简洁？
- 卡片是否清楚？
- 连线是否直观？
- Condition 独立卡片是否合理？
- pass / fail 是否一眼能理解？
- Action 的 done / error 是否有必要同时展示？
- 右侧属性面板是否好懂？
- 底部 trace 是否有用？
- 验证错误是否清楚？
- 首次使用入口是否足够直接？
- 画布是否太拥挤？
- 颜色是否影响阅读？
- 小屏布局是否还能接受？
