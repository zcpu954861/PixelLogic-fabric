# PixelLogic WebUI 视觉概念

本轮原型方向改为 **槽位式横向积木流**。

最高参考是用户草图：

```text
D:\Administrator\Pictures\无标题.png
```

草图强调大块横向拼接、条件高块、上下分支槽位和咬合边。本轮因此继续保留 PixelLogic 的 Graph / Card / Direct Edge 底层模型，但把普通用户看到的表达从“端口和线”改成“块和槽位”。

## 本轮修正

- 卡片更像积木块，而不是散落节点。
- 条件判断是高块，右侧固定“通过 / 失败”两个槽位。
- 分支块直接贴到槽位后方，减少追线。
- 动作的错误输出折叠为小红色错误处理槽位。
- 连接从 SVG 长线改为短粗拼接条。
- 中心画布继续支持拖拽、滚轮缩放、适应视图、回到中心、聚焦选中。

## 非目标

- 不实现后端 runtime。
- 不实现真实保存 API。
- 不实现真实图执行。
- 不修改 Java 后端。
- 不引入 React / Vue / Svelte / 图形库。

## 用户仍需确认

- 是否符合用户草图方向。
- 槽位式横向积木流是否比上一版更少杂乱。
- 条件高块上下槽位是否符合直觉。
- 当前卡片尺寸是否舒服。
- 是否继续保持克制 Pixel Craft，还是更明显地做成拼图玩具感。
